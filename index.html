RestoHunter Leads

Pick a country and a business type, then Generate. You get up to 5 new leads, never one you have had before. Each email is printed on the business's own website and its domain accepts mail. New leads are saved to your Google Sheet's lead list automatically and appear in the Leads tab within an hour.

Settings (one-time GitHub key)

Generate runs on GitHub, so this page needs a GitHub key. It is saved only in this browser.

  1. Open GitHub → New fine-grained token.
  2. Repository access: Only select repositories → RestoHunter-AI.
  3. Permissions: Actions: Read and write and Contents: Read-only.
  4. Generate, copy the key, paste it below and Save.
